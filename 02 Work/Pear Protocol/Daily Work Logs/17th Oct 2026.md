## Unlock amounts were hidden for every upcoming unlock

- [#1122](https://github.com/pear-protocol/agent-pear-v2/pull/1122) (`development`, opened 19:42, merged 20:42 UTC): the agent told a user there were no upcoming emissions or unlock pressure for $XPL (about 227.8M tokens, about 5% of market cap, due 25 Oct and monthly after); KAITO got the same wrong answer in that session (Langfuse `355251280a0d4b45bcfcfe8d1b814f5a`).
- Cause: `getEffectiveUnlockMetrics` nulled amount, value and impact when no allocation had a `committedClaim`. The live Tokenomist v5 API only sets `committedClaim` after the date has passed, so every future event for XPL, KAITO and HYPE was hidden. The formatter then summed nulls to "0.00%" and printed "Unlock schedule manageable", and `get_upcoming_unlocks` dropped the events.
- Fix: schedule amounts come back labelled `SCHEDULED (vesting schedule, not announced; actual claimed amount may be lower)`, the "manageable" line only prints when some unlock has a known size, and the tokenomist prompt says to state the amount is unavailable rather than "no unlocks". Rule kept: an unconfirmed amount is never shown as announced.
- Checked: 6/6 and 2/2 specs, build, tsc and lint clean; node replayed twice each (XPL: next unlock 10/25/2026, 227,777,779 tokens, 5.01%; KAITO: 10/20/2026, 16.4M, 7.43%). Not run: the awareness eval (it never runs the tokenomist node).
- Left open per the PR: the formatter shows only 3 allocations (KAITO 16.4M of about 17.6M), `linearUnlocks` is ignored, and `tokenomist.txt` mentions a `get_unlock_schedule` tool that doesn't exist.
