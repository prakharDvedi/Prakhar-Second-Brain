# IndiaPathy

A premium landing page for a medical clinic/hospital, built with Next.js, Tailwind CSS, and Framer Motion.

## Features

- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop.
- **Modern UI**: Teal/Emerald color scheme with glassmorphism and smooth animations.
- **Sections**:
  - Hero with animated stats
  - Departments Grid
  - Doctor Team Cards
  - Testimonials
  - Blog Previews
  - Interactive Contact Map

## Gettiing Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)
