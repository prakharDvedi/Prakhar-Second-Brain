# Ecom Profit Analyst (Hackathon)

**Update 2026-10-10: the project is now the GST import auditor.** Repo renamed to gst-import-auditor, issues #1 to #11 rewritten, same stage numbers. See [[03 Alternative - GST Import Auditor]] (Update section). The e-commerce text below is the earlier plan, kept as history.

Agent that takes a small online store's messy exports and answers "where am I losing money and what should I change". Every number in the final report is recomputed by code from the raw data.

Hackathon track: "Build an agent that works". Required tools: neatlogs, Entire, cfo.ai. Time budget: 2 days, solo.

- Repo (public): https://github.com/prakharDvedi/gst-import-auditor (was ecom-profit-analyst, redirects)
- Issues: #1 to #11 in the repo, one per stage (Stage 0 is #1, Stage 9 is #10, building in public is #11)
