# Projects

Every personal GitHub project by `prakharDvedi` — owned, not forked. Pulled one-by-one from GitHub READMEs, then split by what the repo actually is: a real build vs. a learning exercise. Forks (`Agent_NPC`, `agent-pear-v2`, `odysseus`, `PanditAI`), the GitHub profile repo, and repos with no README at all (`AirBNB`, `airbnb-clone`, `backendOnly`, `CreditSea`, `golangDB`, `LearnNext`, `pear`) are excluded — deleted from this vault rather than kept as empty stubs.

## Sub-sections

- [[Real Projects]] — 19 repos. Shipped tools, hackathon submissions, freelance work, personal products. Each has a real README describing what it does and why.
- [[Study and Practice]] — 15 repos. Named or written as learning exercises — a first PERN app, "Golang Learnings," a default `create-next-app` scaffold never customized. Kept separate so the resume/portfolio pass doesn't mistake a tutorial repo for a shipped project.
