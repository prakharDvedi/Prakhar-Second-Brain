# Prakhar's Vault

This is a personal "second brain" — an Obsidian vault used to externalize memory: work, learning, decisions, incidents, projects, career, and reflection. It's meant to help thinking, not to become a folder-structure hobby (see [My Identity](01%20Self/My%20Identity.md)).

Start here: [00 Home/Home.md](00%20Home/Home.md) links out to Current Focus, work, projects, self, and reviews.

## Folder map

| Folder | What's in it |
|---|---|
| `00 Home` | Dashboard note — the entry point |
| `01 Self` | Identity, goals, writing style, and [AI Vault Rules](01%20Self/AI%20Vault%20Rules.md) (governs how AI may edit this vault) |
| `02 Work` | Pear Protocol work: daily logs, incidents & investigations, decisions, engineering lessons, resume evidence |
| `03 Projects` | Real projects and study/practice projects |
| `04 Knowledge` | Topic-organized engineering knowledge (AI/LLM systems, backend, databases, distributed systems, security, DevOps, frontend, Web3) |
| `05 Career` | Resume, companies |
| `06 People` | Notes on people |
| `07 Reviews` | Weekly and monthly reviews |
| `08 Writing` | Writing drafts/output |
| `99 Inbox` | Unsorted daily capture |
| `Templates` | Note templates (daily log, incident, decision, weekly/monthly review) |

## How to use

- **Capture freely** into `99 Inbox` or a Daily Work Log during the day — no need to categorize up front.
- **After meaningful work**, update the relevant work/project note, or create an incident/decision note only if it genuinely deserves standalone history.
- **Weekly/monthly**, reviews get compiled from logs and notes into `07 Reviews`.
- Note-taking and AI-editing behavior for this vault is governed by [AI Vault Rules.md](01%20Self/AI%20Vault%20Rules.md) — read it before making structural changes or letting an AI assistant write here.
